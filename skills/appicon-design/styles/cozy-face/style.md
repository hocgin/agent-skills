# 萌脸特写 `cozy-face`

> 参考：`reference.png`。参考图只用于提炼设计语言，它的「奶黄脸 + 双爪环抱白色星星」组合属于参考 IP，见「参考 IP 排除」。

## 设计 DNA（可复用）

| 维度 | 规范 |
|---|---|
| 配色 | 极简 4 色：脸主色一种（按项目选，见下）+ 同色相深一阶阴影 + 深咖黑眼 `#2C241F` + 奶白物件 `#FEF9E9`（边缘暖奶油 `#F9DA9A`） |
| 主色候选 | 蜜桃橙 `#FFB37A`/`#F08A4B`、樱花粉 `#FF9EB5`/`#E8738F`、薄荷绿 `#8EDDB4`/`#5DBE8E`、天空蓝 `#8CCBFF`/`#5BA6E8`、香芋紫 `#C3A8FF`/`#9C7FE6`、珊瑚红 `#FF8A7A`/`#E5604F`；奶黄 `#FFD741`/`#FEBB1E` 仅在物件不是星星时可用 |
| 造型语言 | 角色无轮廓，主色即背景；两颗竖椭圆眼间距宽；无嘴无鼻无耳；圆胖短爪（0–2 只）；物件为圆胖简单剪影 |
| 材质 | 扁平为主，物件略带棉花糖 / 软陶柔软感 |
| 光影 | 无真实光源；仅用同色相深一阶的弧形柔边阴影表现层次；可有 1 处浅色高光点 |
| 构图原则 | 超近景、脸铺满画布被裁切；眼睛 + 一个奶白物件构成全部内容；位置见「版式变体」 |
| 质感 | 干净柔和的数字插画，可有极轻纸感颗粒 |
| 细节密度 | 两眼 + 物件 + 0–2 爪 + ≤1 高光点；物件内部 ≤1 处极简符号；无文字 |
| 情绪 | 治愈、可爱、温暖、陪伴 |

**签名手法**：① 单色无轮廓的脸就是背景；② 只有两颗深色竖椭圆眼，无嘴；③ 一个奶白圆胖物件作为唯一焦点，阴影只用同色深一阶。

## 参考 IP 排除

- 原主体组合：奶黄色脸 + 双爪居中环抱一颗白色五角星。
- 原布局：眼睛在上 1/3、物件居中偏下约 45%、两爪左右对称压住物件、左上一大一小高光点。
- 品牌：Pocket 收藏 App。

## 主体转译规则

主体 = **脸主色** + **奶白物件** + **版式**，三者都要为新项目重新选择：

- **物件**承载核心隐喻，必须简单圆胖：硬币（存钱）、书签（稍后读）、礼物盒（奖励）、对话气泡（聊天）、月亮（睡眠）、水滴（喝水）、爱心（喜欢）、骨头（宠物）、铅笔（日记）、勾选框（待办）……**不得使用星星**。
- **主色**从候选中选与项目调性匹配的一种，整张图只有这一种主色；不要默认奶黄。
- **版式**优先 `peek` / `side-hold`；`hug` 与参考最接近，只在物件和主色都与参考不同时使用。


## 可变元素

- 物件形状及其极简内部符号（不得为星星）
- 脸主色（候选内单色）及其同色深一阶阴影
- 版式、眼睛的细微位置与倾斜（保持两颗竖椭圆）
