# 复古彩条 `retro-stripe`

> 参考：`reference.png`。参考图只用于提炼设计语言，它的主体（一次性相机）、部件和布局都属于参考 IP，见「参考 IP 排除」。

## 设计 DNA（可复用）

| 维度 | 规范 |
|---|---|
| 配色 | 机身米白 `#ECDCC5`；彩条 4 色固定顺序：芥末黄 `#F2BD4B`、橙 `#E97134`、信号红 `#CF312B`、钴蓝 `#15377F`；红色点缀 `#D9392F`；焦点部件近黑 `#111111`；金属 / 透明件为中性银灰 |
| 造型语言 | 敦厚体块、大圆角；零件只用简洁几何（圆、圆角方、胶囊）；比例夸张，焦点部件占画布宽 30–45% |
| 材质 | 米白磨砂 ABS 塑料；焦点为凹陷近黑部件（可为玻璃 / 网孔 / 刻度盘 / 屏面），局部透明棱纹塑料、哑光金属 |
| 光影 | 左上柔和棚拍光；凸起处细腻倒角高光与 AO；无硬投影 |
| 构图原则 | 物体**正面铺满画布**、正视无透视；一个近黑焦点部件；彩条作为机身涂装穿过画面；具体位置见「版式变体」 |
| 质感 | 轻微印刷颗粒与纸感噪点，彩条像丝印涂装，干净不脏旧 |
| 细节密度 | 焦点之外最多 3 个小部件；可有极少量印刷短线；默认无文字 |
| 情绪 | 复古、温暖、怀旧、玩趣 |

**签名手法**：① 米白塑料器物的正面就是图标背景；② 黄–橙–红–钴蓝四色丝印彩条涂装；③ 唯一的近黑凹陷焦点部件，配一处红色点缀。

## 参考 IP 排除

- 原主体：一次性 / 即拍相机及其镜头、取景器、闪光窗、快门键、计数窗。
- 原布局：中下大圆镜头 + 顶部一排窗口 + 左上红色圆按钮 + 右侧小圆计数窗 + 彩条从左边缘中部扫向右下、钴蓝铺满底部。
- 文字：「SNAP」「400」等原字样。

## 主体转译规则

把项目隐喻转译为**一件 70–80 年代米白塑料器物的正面**，优先选**不是相机**的器物：收音机、录音机、计时器、计算器、掌机、电话、台灯、电风扇、对讲机、打字机、秤、门铃……

- 焦点部件承载核心隐喻：喇叭网、表盘、转盘、旋钮、屏面、按键阵列；形状可以是圆、圆角方或胶囊，不必是圆形镜头。
- 红色点缀只出现一次，形态随器物变化（拨杆、指示灯、按键、指针）。
- 隐喻不是实物（如「社交」「AI」）时，把符号做成焦点部件里的浮雕或屏面图案。
- 相机类项目也要换器物或换焦点形态（如胶卷盒、底片放大镜、幻灯机），不能画成带大镜头的相机正面。

## 版式变体

```composition:diagonal-band
Strict front orthographic view with no perspective. The front face of the object fills the entire canvas edge to edge, so the cream body itself is the icon background. One near-black focal part sits slightly above center, about 35–45% of the canvas width, with a thick raised cream bezel. The four livery bands run as one straight diagonal sash from the upper-left area to the lower-right corner, passing behind the focal part. One small red accent sits at the lower left, and at most two small components sit along the top edge.
```

```composition:horizontal-band
Strict front orthographic view with no perspective. The front face of the object fills the entire canvas edge to edge, so the cream body itself is the icon background. One near-black focal part sits in the upper-middle area, about 35–40% of the canvas width. The four livery bands run perfectly horizontally across the lower third of the canvas from edge to edge, with the cobalt band lowest. A short row of two or three small controls sits on the cream area between the focal part and the bands, one of them red.
```

```composition:arc-band
Strict front orthographic view with no perspective. The front face of the object fills the entire canvas edge to edge, so the cream body itself is the icon background. One near-black focal part sits at the exact center, about 40% of the canvas width. The four livery bands curve as concentric arcs around the lower-left side of the focal part, like a quarter rainbow wrapping it. One small red accent sits at the upper right, and the upper-left area stays plain cream.
```

```composition:vertical-band
Strict front orthographic view with no perspective. The front face of the object fills the entire canvas edge to edge, so the cream body itself is the icon background. The four livery bands run vertically down the left third of the canvas from top edge to bottom edge, with the cobalt band at the far left. One near-black focal part sits in the right two-thirds, centered vertically, about 40% of the canvas width. One small red accent sits above the focal part.
```

## 可变元素

- 器物类型与外形细节、焦点部件的形状与内容
- 版式（彩条走向：斜带 / 横带 / 弧带 / 竖带）
- 小部件的形态与数量（上限 3）、红色点缀的形态
- 是否出现品牌字样（仅 `--label`）
