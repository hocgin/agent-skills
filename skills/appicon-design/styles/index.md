## 自动匹配规则

未指定风格时，按下列维度给每个风格打分（0–3 分），取总分最高者；平分时按 **调性 > 行业 > 主体适配** 决胜。

1. **调性**（权重最高）：
   - 复古、怀旧、温暖、玩趣、拟物 → `retro-stripe`
   - 高级、精致、沉浸、质感、拟物 → `luxe-skeuo`（与 `retro-stripe` 同为器物拟物：要怀旧玩趣选 `retro-stripe`，要高端克制选 `luxe-skeuo`）
   - 活泼、潮流、年轻、文字感强 → `pop-letter`（字母标：核心功能难以用单一图形表达、或名字本身就是记忆点时优先）
   - 直观、新鲜、写实、一眼可认 → `real-morph`（项目名或功能本身就是一个具体实物时优先，如「番茄钟」）
   - 治愈、陪伴、温暖、极简可爱 → `cozy-face`（图形隐喻类的可爱风；需要字母标时改选 `jelly-letter`）
   - 甜美、可爱、轻盈、治愈、3D 质感 → `jelly-letter`（与 `pop-letter` 同为字母标：要潮酷对比选 `pop-letter`，要柔和甜美选 `jelly-letter`）
2. **行业**：对照上表「适合项目」及各风格 front-matter 的 `keywords`。
3. **主体适配**：候选隐喻是否满足该风格的「主体适配要求」。
4. **平台调性**：系统工具 / 企业应用倾向克制风格；娱乐 / 生活 / 创作类可接受强风格化。

若所有风格都明显不适配（总分 ≤ 2），告知用户当前风格库没有合适的风格，建议提供案例图新增风格，或在用户同意后使用最接近的风格。

回复中需写明：选中的风格 + 一句理由（如「复古相机、怀旧调性，选 `retro-stripe`」）。
