# 香槟拟物 `luxe-skeuo`

> 参考：`reference.png`（音乐 App 备用图标：黑胶唱机俯视）。与 `retro-stripe` 同为器物铺满画布的拟物风格，区别在于：俯视而非正视、无彩条、用香槟金属与流体渐变表达高级感。

## 视觉特征

| 维度 | 规范 |
|---|---|
| 配色 | 机身暖米白 `#E4D9C9`（暗部 `#D3C5B5`）；主体大面积光泽黑 `#2D2F36`；金属部件香槟金 / 古铜 `#C9AE8A`（暗部 `#826F5C`）；焦点流体渐变：品红 `#CD3C8D` → 朱橙 `#FC4623` → 橙 `#FC663E` → 杏黄 `#FDA147`；点缀：一圈橙色发光环、一个小红 / 橙指示灯 |
| 造型 | 高端音响 / 精密器物，几何精准；大圆盘主体 + 细长弯曲的金属臂 + 圆柱形旋钮；圆角机身、倒角精细 |
| 材质 | 机身磨砂陶瓷感塑料 / 粉末喷涂；金属为香槟金拉丝（旋钮顶面有同心圆拉丝纹）；黑色部件为高光亚克力 / 黑胶，带细密同心纹路；焦点为光滑的彩色流体渐变面 |
| 光影 | 左上柔和棚拍光；黑色部件上有一道斜向宽幅反光；金属有锐利但柔和的高光；部件与机身之间有细腻 AO 与短而柔的接触阴影 |
| 构图 | **正上方俯视**，机身顶面铺满整个画布；主体大圆盘偏左下、约占画布宽度 75%，局部被画布边缘轻微裁切感；右上放一个金属支点 + 斜伸向中心的金属臂；左上一个带橙色发光环的小旋钮；右下 1 大 1 小两个香槟金旋钮 + 刻度点 |
| 质感 | 超写实产品渲染，干净无尘，微妙的材质纹理（拉丝、同心纹）可见 |
| 细节 | 金属部件 3–5 个；刻度点、指示灯等微细节 ≤3 处；**无文字** |
| 情绪 | 高级、精致、温润、沉浸 |

**签名特征**：① 暖米白机身 + 香槟金拉丝金属 + 光泽黑三材质组合；② 中心一块粉橙黄流体渐变的圆形色彩焦点；③ 俯视视角、主体大圆偏左下、金属臂从右上伸入。

## 主体转译规则

把项目隐喻转译为**一件高端精密器物的顶面俯视图**（唱机、音箱、相机机身顶面、腕表表盘、咖啡机、调音台、保险柜转盘……），保持固定骨架：

- 偏左下：一个大号光泽黑圆形主体（唱片、喇叭振膜、镜头、表盘、转盘），中心是**流体渐变圆形色彩焦点**，承载项目的核心隐喻（可在渐变上做浮雕符号）；
- 右上：一个金属支点 / 底座，伸出一根细长弯曲的香槟金金属臂指向主体（唱臂、指针、镊子、拨杆……若隐喻不需要，可换为一个较大的金属旋钮）；
- 左上：一个带橙色发光环的小旋钮；
- 右下：1 大 1 小两个香槟金旋钮 + 少量刻度点。

## 可变元素

- 器物类型与大圆主体的具体内容（纹路、网孔、镜片、刻度）
- 流体渐变焦点上是否有浮雕符号及其形状
- 金属臂 / 指针的形态，或替换为旋钮
- 旋钮、指示灯的具体数量（在上限内）
