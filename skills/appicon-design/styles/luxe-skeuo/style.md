# 香槟拟物 `luxe-skeuo`

> 参考：`reference.png`。参考图只用于提炼设计语言，它的主体（黑胶唱机）、唱臂结构与布局都属于参考 IP，见「参考 IP 排除」。

## 设计 DNA（可复用）

| 维度 | 规范 |
|---|---|
| 配色 | 机身暖米白 `#E4D9C9`（暗部 `#D3C5B5`）；光泽黑 `#2D2F36`；香槟金 `#C9AE8A`（暗部 `#826F5C`）；焦点流体渐变：品红 `#CD3C8D` → 朱橙 `#FC4623` → 橙 `#FC663E` → 杏黄 `#FDA147`；最多一处橙色发光点缀 |
| 造型语言 | 几何精准的精密器物；圆角机身、精细倒角；部件为圆柱旋钮、细长金属件、圆盘或圆角方面板 |
| 材质 | 仅三种：米白磨砂粉末喷涂 / 香槟金拉丝金属（同心拉丝）/ 光泽黑亚克力（可有细密纹路）；焦点为光滑流体渐变面 |
| 光影 | 左上柔和棚拍光；光泽黑上一道斜向宽幅反光；金属锐利柔和高光；细腻 AO 与短柔接触阴影 |
| 构图原则 | 正上方俯视，机身顶面铺满画布；一个光泽黑主元素承载唯一流体渐变焦点；金属部件 2–4 个；位置见「版式变体」 |
| 质感 | 超写实产品渲染，干净无尘，拉丝与同心纹可见 |
| 细节密度 | 金属部件 ≤4，刻度点 / 指示灯 ≤3；无文字 |
| 情绪 | 高级、精致、温润、沉浸 |

**签名手法**：① 米白 + 香槟金拉丝 + 光泽黑的三材质组合；② 唯一一块粉橙黄流体渐变色彩焦点；③ 正上方俯视、机身顶面即背景。

## 参考 IP 排除

- 原主体：黑胶唱机及唱片、唱臂、唱头、转盘。
- 原布局：大黑圆盘偏左下并被裁切 + 右上金属支点伸出弯臂 + 左上橙环小旋钮 + 右下一大一小旋钮。

## 主体转译规则

把项目隐喻转译为**一件高端精密器物的顶面**，优先选**非唱机**器物：音箱、耳机收纳盒、腕表 / 计时器表盘、咖啡机顶面、磨豆机、调音台推子、相机顶部转盘、保险箱转盘、香薰机、温控旋钮……

- 光泽黑主元素可以是圆盘、圆角方面板或胶囊槽；流体渐变焦点嵌在其中，可带浮雕符号表达核心隐喻。
- 金属部件按器物逻辑设置（推子、拨杆、旋钮、表冠、铰链），不得出现「从角落支点伸向圆盘的弯臂」结构。
- 音乐类项目也要换器物（音箱、推子台、耳机盒），不画唱机。
