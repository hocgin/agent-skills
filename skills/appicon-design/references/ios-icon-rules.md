# iOS App Icon 设计规范要点

脚本会把下列规则的英文版自动注入每条提示词（见 `build_prompt.py` 的 `IOS_RULES`），本文件用于人工设计主体与出图验收。

## 画布

- 交付尺寸 **1024×1024 px**，正方形，sRGB / Display P3，**不透明**。
- 交付给 Xcode 的图稿**不预先切圆角**：系统会自动套用超椭圆（squircle）遮罩。因此默认 `--shape square`，主体与背景全出血铺满画布。
- 展示 / 宣传用图可以用 `--shape squircle`，在白底上呈现带圆角的图标。

## 构图

- **单一焦点**：一个主体、一个最强视觉中心；焦点位于画布中心或略偏下。
- **安全区**：关键内容放在中心约 80% 区域内，四角会被圆角遮罩裁掉，不要在四角放重要元素。
- **铺满**：主体或背景要填满整个画布，不要留出大片空白或画成「白底上的小图标」。
- **正视为主**：除非风格另有规定，使用正面或轻微俯视的视角，避免强透视。

## 识别度

- 缩小到 **60px（主屏）/ 40px（设置）/ 29px（Spotlight）** 仍能辨认轮廓与主体。
- 细节有层级：大形 → 焦点 → 装饰；装饰不得抢夺焦点。
- 配色对比清晰，主体与背景有明确的明度差。

## 禁忌

- 不使用真实照片、截图、UI 界面元素。
- **默认不出现文字**；品牌字样仅在用户明确要求且风格允许时，用 `--label` 指定一个短词。AI 模型易生成乱码，字越少越好。
- 不使用 Apple 硬件外观、SF Symbols 原样、其他品牌 Logo。
- 不在图稿中自带投影、外描边、圆角边框、透明背景。

## 验收（通用）

- [ ] 1024×1024 正方形，全出血、无透明、无白边
- [ ] 一个主体、一个焦点，居中
- [ ] 缩小到 60px 后仍可辨认
- [ ] 四角没有关键信息
- [ ] 无多余文字 / 乱码 / 水印
