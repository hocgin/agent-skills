# 风格预设与受控转换

这些是初始化候选。优先继承用户或已保存 Profile 的确切参数；仅在缺省时采用建议值。选择后把参数完整写入 Profile，后续页面不得重新自由选择。

| style 输入（别名） | 主视觉语言与建议起点 | 适配提示与常见漂移 |
| --- | --- | --- |
| `glassmorphism`（`glass`） | 半透明磨砂板、单一漫射主光、清楚的边缘；surface alpha 0.65～0.85、blur 12～24 pt、圆角 20～28 pt、弱阴影 | 天气分层、AI 输入输出或效率卡片；避免透明文字、所有控件发光、玻璃金属随机混用 |
| `skeuomorphic`（`skeuomorphism`） | 一套真实材质、接触阴影、物体结构；固定角度和光源 | 音乐、录音机或输入键；按真实功能造物，避免每页换皮革/木头/铬金属 |
| `minimal`（`minimalism`） | 少量语义色、简单几何、系统或明确替代字体、弱纹理；8 pt 间距、正文起点 17 pt、单页一个焦点 | 效率/专业工具的操作结果；避免等同空白，不能牺牲功能信息 |
| `3d-playful` | 圆润 3D、固定镜头/透视、低对比柔光、受控饱和度；一个主物体、最多 2～3 个辅助物体 | 音乐、学习或健康产品；避免每页换渲染器、塑料突然变写实金属 |
| `editorial` | 字体对比、网格、留白与裁切；标题通常左对齐，一个主要裁切方向 | 内容/文化和品牌表达；海报密度降到移动 UI，中文字体有实现替代 |
| `illustration` | 一种明确技法，如平涂矢量、手绘或纸感拼贴；锁定线宽、纹理尺度、角色比例 | 生活、教育或解释性场景；不得逐页换绘画技法 |

## 无参考图时的选择

按内容解释性和产品调性选择主风格：天气可用自然柔光和玻璃分层；音乐可用实体媒介拟物或编辑式专辑；效率可用克制卡片/时间轴；输入法突出触键和文字秩序；AI 用可读的输入输出转化，抽象视觉作辅助；健康偏柔和场景与清楚趋势。用户明确指定的方向覆盖这些建议。

完全没有调性线索时从 `minimal` 开始：浅中性色底、深色文字、一个主色、8 pt 间距系统、系统字体、单一光源、弱阴影。不要每次随机挑新配色。

## 主次风格与冲突

记录主风格支配维度、次风格影响维度及来源。次风格应能删掉而不破坏主体渲染的一致性。

例如参考海报有米白留白、偏左重心、纸质噪点、硬边黑色大字，用户指定 `glassmorphism`：

- `retained`：米白背景、偏左重心、标题与正文对比。
- `translated`：纸质板转成暖白磨砂玻璃，投影统一左上柔光；大字转成可动态换行的原生标题。
- `dropped`：厚纸撕边和重噪点，避免与干净玻璃边缘冲突。

主风格 glassmorphism，次风格 editorial 仅影响网格和排版。先生成完整新 Profile，再生成页面；不能第一页用纸、第二页才用玻璃。

## 受控变更

输入 `style_id` 无新方向时直接复用。若同时要求“用这个 Profile，但改为拟物”，派生新 ID，在 `derived_from` 记录旧 ID；原文件保持不变。主题/深色模式也需先定义完整 token 组，不能让模型自行反色。
