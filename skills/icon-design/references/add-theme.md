# 新增主题流程

用户提供参考图并要求「新增 / 保存为主题」时执行。**一张参考图 = 一个主题**；若一张图内包含多种风格，先与用户确认取哪一种。

## 1. 观察参考图

逐个图标观察，只提取**所有图标共有**的特征（单个图标独有的属于「可变元素」）。

六维提取清单：

| 维度 | 需要回答的问题 |
|---|---|
| 配色 | 有几种颜色？各自承担什么角色（描边/主填充/阴影/点缀）？估算 HEX |
| 材质 | 平面 / 拟物 / 玻璃 / 黏土 / 渐变？有无纹理、高光？ |
| 光影 | 光源方向？阴影是真实投影、内侧色带、还是没有？ |
| 构图 | 主体占画布比例？是否倾斜？留白？有无容器（圆底/方底）？装饰位置？ |
| 造型 | 几何还是有机？圆角大小？是否拟人？比例特点？**签名特征**（缺口、错位、唯一点缀……） |
| 细节 | 内部符号/表情的形态、颜色、数量；线条粗细（占图标宽度 %）、端点、连接 |

同时总结：情绪关键词（3–4 个）、适合的项目类型、主体适配要求。

## 2. 命名

- `id`：小写短横线，2 个词以内，描述风格而非内容，如 `glass-soft`、`clay-3d`。
- `name`：4 字以内中文名。
- 与已有主题不重名、风格差异明显；若与现有主题高度相似，建议作为现有主题的变体并询问用户。

## 3. 创建文件

```bash
mkdir -p themes/<id>
cp <参考图路径> themes/<id>/reference.<ext>
cp themes/_template.md themes/<id>/theme.md
```

按模板填写 `theme.md`，要点：

- `style` 块：英文、只写「怎么画」、不出现任何具体物体；把签名特征写成可执行的描述；结尾保留 `consistent with a matched icon set.`
- `negative` 块：通用项（gradient/3D/text/watermark…）+ 色板外颜色 + 违背签名特征的项。
- `keywords`：中英文都写，供 `--auto` 匹配。
- `reference` 字段与实际文件名一致。

## 4. 注册

在 `themes/index.md` 的表格新增一行，并在「自动选择规则」的调性列表中补充该主题对应的调性。

## 5. 自检

```bash
python3 scripts/build_prompt.py --list
python3 scripts/build_prompt.py --theme <id> --subject "a house with a door" --subject "a magnifier"
```

- 脚本能解析出 style / negative 块；
- 用参考图中出现过的物体写一个主体描述，确认生成的提示词能「复现」参考图；
- 如有图像生成工具，试生成 1 张网格图，对照验收清单调整 style 措辞（这是唯一允许修改 style 块的时机）。
