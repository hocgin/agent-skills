# 线性点缀 `line-dot`

> 参考：`reference.jpg`（光盘 / 音乐 / 磁带 / 收音机）。

## 视觉特征

| 维度 | 规范 |
|---|---|
| 配色 | 线条深炭灰 `#333333`；唯一点缀暖黄 `#FFD43B`；展示圆底 `#F5F5F5`。2 色 |
| 材质 | 纯线性矢量，无填充（内部透出背景），无纹理 |
| 光影 | 完全无光影；层次只靠线条结构与黄点 |
| 构图 | 单主体居中、正向不倾斜，占画布约 45%；左右基本对称，结构规整 |
| 造型 | 由圆、圆角矩形、弧线等几何元素构建，圆角统一且较大；可用同心结构与内嵌结构（屏幕、喇叭、圆孔） |
| 线条 | 中粗等宽单线，约为图标宽度 5%；圆头圆角；允许开放弧线段（如光盘反光弧） |
| 细节 | **每个图标恰好一处**暖黄点缀：实心小圆点，或一小块实心填充区（如磁带顶部窗）；黄色点缀无描边或被深灰线包围；其余细节用短直线、小圆环 |
| 情绪 | 简洁、克制、清爽、可靠 |

## 可变元素

- 主体物体与几何结构
- 内部细节（短线、圆环、开放弧线）的数量与布局，建议 2–4 个
- 黄色点缀的形态（圆点 / 小块填充）与位置——但数量固定为 1
