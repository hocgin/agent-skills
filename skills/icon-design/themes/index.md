## 自动选择规则

未指定主题时，按下列维度给每个主题打分（0–3 分），取总分最高者；平分时按 **调性 > 行业 > 主体适配** 的优先级决胜。

1. **调性**（权重最高）：
   - 可爱、亲和、陪伴、情感化 → `doodle-buddy`
   - 热闹、刺激、潮流、有能量 → `pop-offset`
   - 专业、克制、高效、可靠 → `line-dot`
   - 稳重、系统级、信任感 → `solid-knockout`
   - 温柔、治愈、轻盈、关怀 → `pastel-layer`
   - 直观、生活化、一眼可认 → `flat-object`
   - 安静、理性、素雅、内容为先 → `mono-thin`（与 `line-dot` 的区别：无点缀色、更细、圆角更小）
   - 潮酷、创意、有设计感、个性 → `glow-blob`
   - 通透、精致、现代、高级感 → `frost-glass`（与 `pastel-layer` 的区别：后层高饱和渐变 + 前层半透明磨砂，而非平涂粉彩）
   - 醒目、活泼、直接、商业感 → `ink-block`（与 `solid-knockout` 的区别：细节用纯黑实心部件而非白色镂空，色彩更明快，边缘带手工感；与 `pop-offset` 的区别：无描边、无错位色块）
   - 温暖、可触、立体、玩具感 → `clay-soft`（唯一的 3D 主题；用户明确要求「立体 / 3D / 黏土」时优先）
2. **行业**：对照上表「适合项目」及各主题 front-matter 的 `keywords`。
3. **主体适配**：候选隐喻是否满足该主题的「主体适配要求」。
4. **用户群**：儿童/学生 → 倾向 `pop-offset` 或 `doodle-buddy`；职场/开发者 → 倾向 `line-dot`、`mono-thin`、`solid-knockout` 或 `frost-glass`；女性/家庭 → 倾向 `pastel-layer`。

回复中需写明：选中的主题 + 一句理由（如「效率工具、调性克制，选 `line-dot`」）。

辅助命令（关键词匹配，仅供参考，最终以上述规则判断）：

```bash
python3 scripts/build_prompt.py --auto "番茄钟 专注 效率工具"
```
