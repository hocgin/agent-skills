# 主题注册表

| ID | 名称 | 一句话风格 | 适合项目 | 主体适配要求 |
|---|---|---|---|---|
| `doodle-buddy` | 涂鸦萌宠 | 粗黑断口手绘轮廓 + 紫色表情 + 青柠绿月牙 | 社交、社区、聊天、宠物、日记、情绪、年轻化生活类 | 主体能被拟人化为软胖小生物 |
| `pop-offset` | 波普错位 | 炭黑粗描边 + 柠檬黄填充 + 薄荷绿错位色带 | 游戏、娱乐、派对、直播、票务、少儿教育、购物活动 | 主体能用几何骨架概括，可倾斜 |

## 自动选择规则

未指定主题时，按下列维度给每个主题打分（0–3 分），取总分最高者；平分时按 **调性 > 行业 > 主体适配** 的优先级决胜。

1. **调性**（权重最高）：
   - 可爱、亲和、陪伴、情感化 → `doodle-buddy`
   - 热闹、刺激、潮流、有能量 → `pop-offset`
   - 专业、克制、高效、可靠 → `line-dot`
   - 稳重、系统级、信任感 → `solid-knockout`
   - 温柔、治愈、轻盈、关怀 → `pastel-layer`
   - 直观、生活化、一眼可认 → `flat-object`
2. **行业**：对照上表「适合项目」及各主题 front-matter 的 `keywords`。
3. **主体适配**：候选隐喻是否满足该主题的「主体适配要求」。
4. **用户群**：儿童/学生 → 倾向 `pop-offset` 或 `doodle-buddy`；职场/开发者 → 倾向 `line-dot` 或 `solid-knockout`；女性/家庭 → 倾向 `pastel-layer`。

回复中需写明：选中的主题 + 一句理由（如「效率工具、调性克制，选 `line-dot`」）。

辅助命令（关键词匹配，仅供参考，最终以上述规则判断）：

```bash
python3 scripts/build_prompt.py --auto "番茄钟 专注 效率工具"
```
