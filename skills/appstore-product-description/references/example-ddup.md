# 范例：DDUP 输入法（来源：App Store 线上文案）

```
打中文的时候，也能顺手认识一个英文或日文词。

DDUP输入法把译词放在中文候选词上方。输入熟悉的拼音、选择想表达的词，顺便看看它的英文或日文释义，让日常打字多一个认识词汇的机会。

【打字时，看看译词】
开启候选译词，在英文和日文之间选择。译词用于词汇参考，不提供整段文字翻译。

【用你熟悉的方式输入】
支持中文全键盘、九宫格和英文键盘。中文支持全拼、简拼与整句候选；候选列表可展开，方便查找。

【选一款自己的键盘】
浅色、深色、薄荷、樱花、纸张、海洋与午夜主题，或跟随系统外观。字体支持系统样式，也可导入 TTF／OTF 字体文件。

【少重复，多表达】
保存常用语，在键盘工具面板中快速插入。表情按分类浏览，最近使用的表情也能快速找到。

【按自己的习惯调整】
按需开启触感、按键音、字符气泡与空格滑动移动光标；英文支持句首自动大写和双空格句号。

开始使用：在 iPhone 或 iPad 的「设置 → 通用 → 键盘 → 键盘 → 添加新键盘」中添加 DDUP，再通过地球键切换。同步主题、字体与常用语等个性化设置需要允许完全访问；未开启时键盘使用默认设置。

从一句话开始，把喜欢的风格放进键盘里。

「订阅取消说明」
1. 订阅为自动续费服务，确认购买后，费用将通过用户的 iTunes 账户扣除。
2. 会员有效期结束前 24 小时，系统将自动从账户中扣费并延长 1 个月的会员服务。
3. 如需取消订阅，请至少在当前订阅期结束前 24 小时手动关闭自动续订功能。
4. 取消路径：打开 iPhone「设置」> 进入「iTunes Store 与 App Store」> 点击「Apple ID」> 选择「查看 Apple ID」> 在「账户设置」中点击「订阅」> 找到并取消“连续订阅”。

「隐私协议 & 服务协议」
- 隐私协议: https://logspot.hocgin.top/DDUP/?active=privacy-policy
- 服务协议: https://logspot.hocgin.top/DDUP/?active=terms-of-service
```

## 结构拆解
