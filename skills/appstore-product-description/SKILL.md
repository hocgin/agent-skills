# appstore-product-description

产出可直接粘贴到 App Store Connect「描述」字段的**纯文本**文案。结构固定为：

```
正文（可变，按 App 撰写）
「订阅取消说明」（固定，原样输出）
「隐私协议 & 服务协议」（固定模板，仅替换两个链接）
```

格式范例见 [references/example-ddup.md](references/example-ddup.md)（DDUP 输入法线上文案）。

## 输入

向用户确认（已给出的不要重复问）：

1. **App 名称与一句话定位**
2. **核心功能 / 卖点**（3–6 条，越具体越好）
3. **使用前置步骤**（如需在系统设置中开启权限、添加键盘、授权等；没有则省略「开始使用」段）
4. **隐私协议链接、服务协议链接** —— 用户提供；未提供时保留占位符 `{PRIVACY_URL}` / `{TERMS_URL}` 并明确提示，**不得编造链接**
5. **是否含订阅**：含订阅则输出固定的订阅取消说明；明确无订阅则省略该块并告知用户

## 正文格式（可变部分）

1. **第一行：一句话主张**（≤ 20 字），说清用户得到什么，不堆形容词。
2. **导语段**（2–3 句）：先讲产品怎么工作，再讲对用户的好处。
3. **功能块 × 3–6**：每块格式严格为

   ```
   【动词短语或利益点标题】
   1–3 句说明，具体到功能、选项、支持范围。
   ```

   - 标题用【】包裹，≤ 10 字，口语、动作导向（如「打字时，看看译词」「选一款自己的键盘」）。
   - 块与块之间空一行。
   - 正文写能做什么、能选什么，不写空泛赞美。
4. **开始使用段**：以「开始使用：」开头，一句话给出操作路径，路径用「设置 → 通用 → …」箭头格式；如有可选权限，说明「未开启时的默认行为」。
5. **收尾金句**：一句话，呼应第一行主张，独占一行。

### 写作约束

- 简体中文；纯文本，**不使用 Markdown**（无 `#`、`**`、表格），列表只用「1.」或「-」。
- 全文（含固定块）≤ 4000 字符。
- 不写无法证实的数据与绝对化用语（"第一""最强""100%"），不提及其他平台 / 竞品名称，不写价格与促销（App Store 另有字段）。
- 能力边界要如实写明（如「译词用于词汇参考，不提供整段文字翻译」），避免误导审核与用户。
- 权限 / 数据相关表述必须与实际行为一致。

## 固定块 1：订阅取消说明（原样输出，不得改写）

```
「订阅取消说明」
1. 订阅为自动续费服务，确认购买后，费用将通过用户的 iTunes 账户扣除。
2. 会员有效期结束前 24 小时，系统将自动从账户中扣费并延长 1 个月的会员服务。
3. 如需取消订阅，请至少在当前订阅期结束前 24 小时手动关闭自动续订功能。
4. 取消路径：打开 iPhone「设置」> 进入「iTunes Store 与 App Store」> 点击「Apple ID」> 选择「查看 Apple ID」> 在「账户设置」中点击「订阅」> 找到并取消“连续订阅”。
```

## 固定块 2：隐私协议 & 服务协议（仅替换链接）

```
「隐私协议 & 服务协议」
- 隐私协议: {PRIVACY_URL}
- 服务协议: {TERMS_URL}
```

## 输出

1. 先输出完整文案（正文 + 两个固定块，块之间空一行），放在一个代码块中便于复制。
2. 之后用一两句话说明：字符数、是否仍有未填的占位符、做了哪些取舍。
3. 用户要求保存时，写入其指定路径；不要自行新建文件。
