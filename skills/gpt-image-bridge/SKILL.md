# gpt-image-bridge

使用随 skill 分发的 `bin/gpt-image-2` 调用 `codex exec` 的 `image_generation` 工具，生成 PNG 并复制到指定位置。无需配置图片 API Key；请求使用当前 Codex 登录账户的权限和额度。脚本名称保留上游兼容性，实际图片模型由 Codex 决定，不保证具体版本；不要把图片模型名传给 `codex --model`，后者选择的是编码模型。

## 准备

- 需要 Bash、可在 PATH 找到的 `codex`，以及支持图片生成的 ChatGPT 登录账户。
- 用 `codex login status` 检查登录；缺少 CLI 时按用户环境安装，未登录时引导运行 `codex login`。不要读取或输出认证文件。
- 将下文的 `SKILL_DIR` 替换为当前 `SKILL.md` 所在目录的实际绝对路径。不要假定安装在 `~/.claude` 或当前项目内。

## 调用

```bash
"$SKILL_DIR/bin/gpt-image-2" "<详细提示词>" "/absolute/output.png" \
  [--size WxH] [--ref /path/to/reference.png]...
```

1. 根据用户意图写出构图、主体、光线、风格和需要呈现的准确文字；已有明确要求时直接执行。
2. 选择输出路径，先创建父目录。调用时对提示词和路径分别引用，避免 shell 将内容当作命令。调用方应使用绝对输出路径；脚本也兼容相对输出路径。
3. 用户要求编辑现有图片时，将实际文件通过 `--ref` 传入。多张图片按照命令顺序传递，在提示词中说明每张的作用。明确写出“只修改 X；保持 Y、Z 不变”。参考图支持相对路径、绝对路径和含空格的路径，脚本会先检查文件存在并转换为绝对路径。
4. 只有用户指定尺寸或版式需要时才传 `--size`。该参数是提示词中的尺寸请求，输出不保证严格匹配；需要时检查实际尺寸。参考图编辑会重新生成整张图，未修改区域也可能发生轻微变化。
5. 生成可能需要数分钟。使用可持续轮询的进程会话，按工具支持的短等待间隔读取进度，避免因单次调用超时而重复提交并消耗额度。
6. 成功时 stdout 仅输出最终绝对路径。读取并检查图片，然后展示给用户；本地媒体链接使用绝对路径。

纯裁剪、精确缩放、格式转换等机械处理使用相应本地工具。此桥接用于 AI 生成与重绘。

## 错误处理

- 参数错误或参考图不存在：修正参数后再调用；此时不会启动生成。
- 找不到 `codex`：先解决 CLI 安装或 PATH。
- Codex 执行失败或没有生成 PNG：检查 stderr 指向的日志和临时目录；如实报告失败，不将旧输出当成新结果，不自动无限重试。
- 成功时清理临时目录和日志；失败时保留以便诊断。生成失败不会覆盖已有输出文件。
