# 接口定义与类型说明

```text
gpt-image-2 "<prompt>" <output.png> [--size WxH] [--ref <image>]...
```

| 参数 | 类型 | 行为 |
| --- | --- | --- |
| `prompt` | 字符串，必填 | 图片描述；作为单个 shell 参数传入 |
| `output.png` | 文件路径，必填 | 父目录必须存在；成功后复制 PNG，允许覆盖已有文件 |
| `--size WxH` | 可选字符串 | 追加 `SIZE:` 提示，不强制校验或缩放输出；重复时取最后一个值 |
| `--ref <image>` | 可重复文件路径 | 检查文件存在；转为绝对路径后逐个传递为 `--image=<path>`，保留顺序 |

参数选项放在两个位置参数之后。未知选项、缺少选项值和空选项值都会报错。`--ref` 接收本地文件，不下载 URL，也不检查文件编码；应提供当前 Codex 版本支持的图片格式。`--size` 不限制固定枚举值。

## 输出

- 成功：stdout 输出最终绝对路径及换行，退出 `0`。
- 参数错误、输出目录不存在、参考图不存在：stderr 输出原因，退出 `2`。
- 找不到 Codex：stderr 输出安装提示，退出 `127`。
- Codex 非零退出或没有生成 PNG：stderr 输出日志末尾和日志路径，退出 `1`。
- 其他文件系统错误：保留 Bash 或底层命令的非零退出码。

`TMPDIR`（默认 `/tmp`）决定临时目录根路径，必须已存在且可写。`PATH` 用于查找 `codex`，以及 Windows 下可选的 `cygpath`。脚本不读取 API Key，也不自行登录。
